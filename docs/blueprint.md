# **App Name**: InsightEdge Hub

## Core Features:

- Interactive Workshop Booking: Allow users to view, filter, and book workshops directly through the platform, streamlining the registration process and automating confirmations. Allow collecting basic background information so that workshops can be tailored to attendees' requirements.
- Personalized Service Recommendations: Implement an AI tool that suggests the most relevant InsightEdge services (e.g., workshops, consulting, statistical services) based on user profiles and their interaction history on the website. It will examine behavior to prioritize the most appropriate suggestion for the customer.
- Automated Event Updates: Automatically populate and update event listings and details on the website, including date, time, location, and registration links.
- Integrated Testimonial Carousel: Display a carousel of impactful testimonials from past participants, dynamically updating on the homepage to build trust and showcase positive outcomes.
- Team Profile Showcase: Present team member profiles in an engaging grid layout, each featuring a circular photo, name, role, and tagline, with hover-expand functionality for a mini-bio.
- Contact Form Management: Streamline contact requests via a structured form with dropdown options for inquiry types and automated confirmation messages, ensuring efficient communication.

## Style Guidelines:

- Primary color: Soft lavender (#D0BFFF), inspired by the blend of psychology and learning, providing a calming and intellectual feel. It contrasts well against the desaturated background, and doesn't feel too cliched.
- Background color: Very light grayish-purple (#F0F0F5). It provides a gentle backdrop that complements the lavender.
- Accent color: Pale blue (#B0E2FF), placed on the 'left' side of lavender on the color wheel, to highlight calls to action and key interactive elements, ensuring visibility and user engagement.
- Headline font: 'Playfair', a serif font for headings. Body font: 'PT Sans' a sans-serif font for body text. Using 'Playfair' paired with 'PT Sans' will create a sophisticated and readable experience for users.
- Use clean, modern icons that represent each service and event type, maintaining consistency and clarity across the platform.
- Employ a grid-based layout with clear content sections, ensuring a visually balanced and intuitive browsing experience on all devices.
- Incorporate subtle animations on scroll and hover effects to add dynamism and enhance user engagement without overwhelming the user experience.
